# MAS — 移动自动化系统（Mobile Automation System）

在 Android 设备上**本地运行**的通用自动化工作流平台：可视化流程编辑 + 后台虚拟屏执行 + 定时任务 + 自定义节点扩展。

无需 PC、无需模拟器。通过 Shizuku/Root 可获得完整的系统级自动化能力。

## 特性

|  | 特性 | 说明 |
|---|---|---|
| 🧩 | **脚本工坊** | 可视化节点图编辑器：执行 / 判定 / 控制三类节点 + 连线逻辑（顺序/是/非/与/或）+ 突发处理 |
| 🎨 | **自定义节点** | 用 JSON 模板定义自己的节点（执行/判定/控制，可带参数与执行命令），系统自动识别 |
| 🖥 | **后台虚拟屏** | 目标应用在虚拟显示器中运行，不打扰前台；实时预览 + 触摸映射 |
| ⏱ | **定时任务** | 按预设时间自动启动流程 |
| 🔗 | **配置绑定流程** | 后台任务配置绑定工坊流程，流程更新自动同步 |
| 📋 | **运行日志** | 全量执行日志、服务/应用状态监控 |

## 快速上手

1. **脚本工坊**：新建流程 → 添加节点（执行/判定/控制/自定义）→ 连线 → 保存
2. **后台任务**：引用流程（自动新建配置）或 🔗 绑定流程（自动同步）
3. **开始任务**：FlowEngine 按流程逻辑在虚拟屏执行，实时预览 + 日志

详细功能见工坊页 ⓘ 使用指南（分页）。

## 构建

```bash
# 常规构建
./gradlew assembleDebug

# 手机端（aarch64）打包
bash scripts/mobile_build.sh
```

## 目录结构

```
app/src/main/java/com/yuanqian/autofarm/
├── presentation/view/workshop/   # 脚本工坊（FlowModels/FlowEngine/编辑器/自定义节点）
├── presentation/view/background/ # 后台任务（虚拟屏预览/任务链/配置绑定）
├── schedule/                     # 定时任务
└── ...                           # 服务层/数据层/领域层
```
